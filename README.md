# PhazonBeyond

Experimentelles PS5-Projekt. In `sce_sys/` liegen die Launcher-Grafiken und die vorbereiteten Anzeigenamen für das Paket. Die vollständige Paketidentität und ein installierbarer Release-Build stehen noch aus.

Der [Projektstand](PROJECT_STATE.md) enthält die technischen Nachweise. Der [Release-Platzhalter](release/PROSPERO-STORE.md) hält die Angaben für die spätere Store-Einreichung fest.
