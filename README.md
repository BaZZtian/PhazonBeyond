## Download and availability

**Not yet available.** There is no public PS5 package, preview or playable demo. Future downloads will be published on [GitHub Releases](https://github.com/BaZZtian/PhazonBeyond/releases).

PhazonBeyond has an accepted Coming-soon reservation in the [Prospero Store catalog](https://github.com/darkxex/ps5-homebrew-catalog/pull/1315). It does not provide an installable release yet.

## Installation

There is currently no package to install. Installation and game-data setup instructions will accompany the first verified release. The files in this repository are not an installable PS5 game.

## Compatibility

PS5 firmware, loader support and compatible game editions have not been validated for a playable release. No gameplay or controller compatibility is currently claimed.

Original game files are not distributed here. Requirements for preparing your own game data will be specified with the release; no data placement or conversion procedure is available yet.

## Controls, saves and updates

Controls, save locations, backup steps and update compatibility will be documented after testing. There is no released version to update or migrate from.

## Support

Contact the maintainer through [GitHub Issues](https://github.com/BaZZtian/PhazonBeyond/issues). For future release reports, include the PhazonBeyond version, PS5 firmware, loader and steps to reproduce the issue. Do not upload game files, keys, personal saves or credentials.
